# 玄玑 Market Trace｜A股百亿成交触板与次日溢价

玄玑旗下的响应式市场样本观察网站，展示 2026-06-14 至 2026-07-13 期间，当日最终成交额不低于 100 亿元且盘中触及涨停价的 A 股样本，并提供玄玑微信小程序入口。

在线访问：[Market Trace 市场样本观察](https://ymj8903668-droid.github.io/market-trace/)

网站支持在沪深300、上证指数和中证1000之间切换。指数涨跌方向通过数据点外圈表达，并同步更新上涨日/下跌日样本的次日平均开盘溢价与悬停详情。

图表中的涨停收盘、炸板、触板顺序和指数涨跌日均可独立勾选显示。组合筛选采用“类别内并列、维度间同时满足”的口径，并实时更新当前样本数、筛选均值与极值标注；上方市场环境汇总始终保持全样本口径。

## 本地运行

```bash
npm install
npm run dev
```

## 生产构建

```bash
npm run build
```

构建产物位于 `dist/`，可部署到任意静态网站托管服务。Vite 会在 GitHub Actions 中自动使用仓库子路径，本地构建则保留相对资源路径。

仓库内置 GitHub Pages 工作流。每次推送到 `main` 都会依次执行依赖审计、自动测试、生产构建和公网部署；Pull Request 只执行质量检查，不发布生产版本。

## 数据口径

- 样本：Tushare 涨停/炸板明细中的 U（涨停收盘）与 Z（炸板）。
- 成交额：用日线行情复核当日最终成交额不低于 100 亿元。
- 触板顺序：同日合格样本按首次触板时间升序做密集排名，同秒并列。
- 次日开盘溢价：次一交易日开盘价 ÷ 次日前收盘价 − 1。
- 指数环境：触板当日指数收盘涨跌幅；上涨/下跌分组按股票只次统计，不按交易日等权。
- 本站为历史样本研究，不构成投资建议。

数据字段说明见 [`DATA_SCHEMA.md`](./DATA_SCHEMA.md)。
